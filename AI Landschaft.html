From Prompt to Agentic AI

A simple view of what an AI agent is, how prompts, instruction files, skills, tools and enterprise knowledge work together, and where Microsoft Copilot Studio and Snowflake Cortex Code fit into the enterprise AI landscape.

The core idea

An AI agent is not only a chatbot. It receives a goal, uses persistent instructions and reusable skills, chooses tools and enterprise data, performs work, checks results, and returns an answer or action with a human in control.

1 · What makes an AI agent?

1

Prompt

The current request. Example: “Check missing SAP OPP mappings and create a report.”

2

Agent

The orchestrator. It interprets the goal, plans steps, uses tools and evaluates outcomes.

3

Instruction / MD file

Persistent project rules. Example: CLAUDE.md controls language, naming, folders and safety rules.

4

Skill

Reusable know-how or SOP for one job. Can bundle steps, checks and scripts.

5

Tool

The agent's hands. Examples: Outlook, SharePoint, SQL, Python, Power Automate.

6

Knowledge / Data

The information the agent may access, limited by identity, permissions and roles.

Landing layer: source data arriving from SAP OPP. Own schema: transformation procedures contain the business/data logic; Snowflake Tasks orchestrate when procedures run and how pipeline steps are sequenced. Semantic View: provides business meaning on top of prepared data and becomes the governed data basis for natural-language questions.
